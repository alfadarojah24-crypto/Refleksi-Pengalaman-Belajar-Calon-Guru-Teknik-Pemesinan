# E-Portofolio PPG · Nurudlucha Alfa Darojah

Website statis (HTML, CSS, JS tanpa proses build).

## Menayangkan di GitHub Pages
1. Buat repositori baru, misalnya `eportofolio-ppg`.
2. Unggah seluruh isi folder ini (`index.html`, `assets/`, `dokumen/`).
3. Buka Settings > Pages, pilih Deploy from a branch, branch `main`, folder `/ (root)`.
4. Alamat situs: `https://<nama-akun>.github.io/eportofolio-ppg/`.

## Struktur
- `index.html`: seluruh konten
- `assets/`: foto dokumentasi
- `dokumen/`: berkas LK (.docx)
